# HS Vindusvask

Statisk nettside for HS Vindusvask, bygget i vanlig HTML, CSS og JavaScript. Den kan deployes direkte fra GitHub til Netlify uten byggesteg.

## Netlify

- Build command: la feltet stå tomt
- Publish directory: `.`
- Base directory: la feltet stå tomt

Netlify kan også hente innstillingene fra `netlify.toml`.

## Tilpasning

- Hovedbildet ligger i `assets/rentvann-vindusvask.webp`.
- Telefonnummer og e-post kan endres i `index.html` og `script.js`.
- Skjemaet åpner et ferdig utfylt e-postutkast til `post@hsrens.no`; det lagrer ikke innsendte forespørsler på nettsiden.
- Logoen er en foreløpig typografisk HS-lockup i samme blå profil. Bytt den gjerne med den originale HS-logoen når en ren logo-fil er tilgjengelig.

## Lokal forhåndsvisning

Åpne `index.html` i en nettleser.
